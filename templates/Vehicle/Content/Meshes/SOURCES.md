# Where everything in this template comes from

Nothing is third-party. All geometry, sound and effects were written for this template.

| Files | Source |
|---|---|
| `Meshes/*.ocmesh` | Procedural: `templates/Vehicle/make_vehicle_template.py` (shapes in `vehicle_geo.py`) writes Wavefront OBJ into `templates/Vehicle/Source/`, and `AverAssetC convert` cooks each into the `.ocmesh` here. The shapes are boxes, tapered boxes and cylinders; the wheels carry spokes so that spin is visible |
| `Sounds/Engine_Idle.wav`, `Sounds/Engine_High.wav` | Synthesised: a fundamental and six harmonics with a slow amplitude wobble, each an exact number of cycles long so the loop is seamless. Replace them by editing two paths in the `AUDIO` record of the `.ocvehicle` |
| `Sounds/Skid.wav`, `Sounds/Crash.wav` | Synthesised: band-limited noise with a slow swell (looped); a decaying low sine sweep and a noise burst |
| `Particles/TyreSmoke.ocparticle`, `Particles/Sparks.ocparticle` | Hand-written effect files |
| `Vehicles/*.ocvehicle`, `Input/*`, `UI/*`, `Maps/*`, `Scripts/*` | Hand-written text, generated by the same script so the graphs are checked against the node reference |

The meshes use no textures and no materials of their own; they draw with the engine's default material until you assign one.

To regenerate: `python templates/Vehicle/make_vehicle_template.py` (add `--no-import` to skip the cook, `--assetc <path>` if `AverAssetC` is not
at `build/bin/AverAssetC.exe`). A template copies only `Content/`, so the script and `Source/` stay in the engine repository.
