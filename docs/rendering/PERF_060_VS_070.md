# 0.6.0 vs 0.7 frame cost (2026-10-06)

NewSponza (PTTest), RX 7800 XT, D3D12, Release builds, owner's settings: render scale 0.5, Path Tracing off,
frame generation on, TAA off, NeuRAA on, project denoiser FidelityFX. GPU ms per rendered frame from
`--gpu-timing`. 0.7 averages the second half of the run; 0.6.0 averages the whole run, so its one-off load
work (voxelise, acceleration structures, air visibility) is slightly inflated.

| Build | Still camera | Moving camera |
|---|---|---|
| v0.6.0 (9e0cfe08) | 17.4 ms | 14.8 ms |
| 0.7 (25b381a2), FidelityFX | 16.7 ms | 14.3 ms |
| 0.7, NRD2 + stabiliser | 15.9 ms | - |

The owner's 10x slowdown was settings, not code: render scale 1.0 (reset by the crash guard on 10-05) and
`RENDER.PATHTRACING 3` (3 bounces) in PTTest. At scale 1.0 with Path Tracing tier 3 both builds take about
110 ms; with Path Tracing off, 59 ms.
