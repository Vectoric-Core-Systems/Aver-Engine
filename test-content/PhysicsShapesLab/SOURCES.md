# Sources

Everything in this folder is generated by `make_shapes_lab.py` (stdlib Python): the OBJ meshes are procedural boxes, a wedge, an octahedron and a
16-sided drum; the text assets (`.ocsurf`, `.ocmat`, `.ocshape`, `.ocworld`, `Game.ocproject`) are written by the same script. No third-party
asset, texture, sound or model is used. The stand-in cube is the engine's built-in `Meshes/cube.ocmesh`.
