# The oracle's expected raw 8-bit probe codes for the RELEASE build, one line per
# (configuration | gate | r,g,b). Read by scripts/gates.ps1 -Release.
#
# WHY THIS FILE EXISTS SEPARATELY FROM gates.baseline.txt: optimisation settings change
# floating-point codegen -- contraction, vectorisation, reassociation -- so a Release probe code may
# legitimately differ from the Debug one by a code or two. A shared baseline would have to either
# tolerate that (and stop being bit-exact) or forbid it (and fail for a reason that is not a bug).
#
# MEASURED 2026-07-21 on an AMD Radeon RX 7800 XT (driver 32.0.23027.2005), /O2 /Ob2 /DNDEBUG,
# /fp:precise (no /fp:fast anywhere in the build -- see docs/STATUS.md 4i).
#
# Every one of the 152 gates came out BIT-IDENTICAL to the Debug baseline, so this file is that
# file's values. That is a result, not a shortcut: nothing in this renderer's shading happens on the
# CPU. The probe reads an 8-bit backbuffer written by HLSL the GPU compiles itself, and the host code
# in front of it only assembles matrices and constants. Host optimisation had nothing to move.
#
# One gate (no-rt/gi-debug) missed twice inside the sweep and then measured correct 8 times out of 8
# in isolation and correct again through the runner: that is docs/STATUS.md 4d item 22, the
# unexplained plausible-wrong-pixel flake, and it is NOT a Release difference.
