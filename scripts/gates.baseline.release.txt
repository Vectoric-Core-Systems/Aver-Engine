# floating-point codegen -- contraction, vectorisation, reassociation -- so a Release probe code may
# legitimately differ from the Debug one by a code or two. A shared baseline would have to either
# tolerate that (and stop being bit-exact) or forbid it (and fail for a reason that is not a bug).

# /DNDEBUG, /fp:precise (no /fp:fast anywhere in the build -- see docs/STATUS.md 4i).
#

# re-recorded twice in between (8b85fcc, d8fc062) and this one was not carried along, so the two
