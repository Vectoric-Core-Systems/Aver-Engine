# Contributing to this project

This document will explain the rules of contributing to this repository

# Overview

A contribution is defined as any content (regardless of pictures, code, suggestions etc.) that is directly stored in this repository will land under the rules of this document. 
A contribution will be governed by the rules in this document

# Rules

1. A contribution need not be your original idea, it can be from someone else but take note do not steal ideas without the original person knowing.

2. AI agentic code is allowed alongside human code, however you must make sure that your code is safe and you will be responsible for what you submit

3. Once a contribution is given, you are giving an irrevocable, worldwide , royalty-free , fully paid up license to use it worldwide in this repository under the GNU Lesser General Public License

4. Make sure any code that you use that is not original from you is attributed (by either linking the original repo or file it was from, name it as 'ATTRIBUTION_<name_of_file_in_the_original_repo>'relicensable under the GNU Lesser General Public License (so code under GNU Affero General Public License or GNU General Public License in this case will not be accepted)

5. Contributiors must have a valid license of Aver under the GNU Lesser General Public License or another license if not given from this original source of the engine (Please state where, we have to verify and prevent violations of the license)

6. Make useful contributions and do not duplicate others issues.

# How to Contribute

We accept code contributions by pull request only, if you are reporting an issue open one in the [issues](https://github.com/Vectoric-Core-Systems/Aver-Engine/issues). For pull requests of code open one in [Pull Requests](https://github.com/Vectoric-Core-Systems/Aver-Engine/pulls)
If you would like to contribute something other than code such as images you wish to be presented on the front page, join the [Discord](https://discord.gg/B5pTrkUN8B) and drop a message in the suggestions channel or showcase channel and ping @Dev team

In addition to code for pull requests, please state any third party dependencies needed by your code including those already in the engine (for module management)

# Review Process

All code will be reviewed in the following process

1. An antivirus scan is run by a random web antivirus provider

2. Code is downloaded to local disk for testing

3. Scan of the code briefly for any obvious issues for small commits by hand (me) or in larger commits by Microsoft Visual C++ Compiler

4. Code is stress tested along with other pull requests (usually done once a month with a maximum of 30 PRs in 1 go, it will be more frequent if there are more PRs)

5. Test with external testers on different hardware (a.k.a. Intel CPU instead of AMD CPU, NVIDIA GPU instead of AMD GPU, or Intel GPU etc.)

6. Code is merged into main repo
